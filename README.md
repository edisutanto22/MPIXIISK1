# Media Pembelajaran Interaktif Arduino Uno

Media pembelajaran Informatika SMA Kelas XII, dibuat dengan HTML, CSS, dan JavaScript murni. Tidak membutuhkan framework atau CDN.

## Menjalankan di komputer
1. Ekstrak seluruh file ke satu folder.
2. Pastikan `index.html`, `style.css`, dan `script.js` berada di folder yang sama.
3. Buka `index.html` dengan Google Chrome atau Microsoft Edge.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload ketiga file (`index.html`, `style.css`, `script.js`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai; URL situs akan tampil di bagian Pages.

Penting: jangan mengganti nama file CSS/JS kecuali tautan di `index.html` juga diubah.
